# Current scope

Use the existing trained XGBoost with the contributor Go collector and FastAPI.
Retraining is optional. PCAP/live windows become a 22-feature table through an
explicitly approximate adapter, with downloadable CSV and persisted predictions.
The actual model artifact and measured inputs are traceable. Network-changing
actions remain disabled; the UI is a later milestone.

The user accepts approximate packet representation for this prototype. Technical
integration does not establish live model accuracy. See agents/ for current
contracts and collector-go/README.md for commands.
